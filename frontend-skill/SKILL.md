# Frontend Skill

## Язык работы

- Агент отвечает пользователю на русском языке.

## API и backend

- Клиенты для работы с backend API не пиши вручную, а генерируй из OpenAPI-схемы проекта.
- Если задача затрагивает генерацию клиентов, интеграцию с backend или организацию API-слоя, сначала прочитай `references/api-generation.md`.

## Базовые правила размещения

Определяй размещение в таком порядке:

1. Route-level экран -> `src/pages`
2. Крупный блок внутри страницы -> `src/widgets`
3. Пользовательский сценарий -> `src/features`
4. Стабильная доменная сущность -> `src/entities`
5. UI, утилиты, store, API, assets и инфраструктура -> `src/shared`

Если модуль может жить на более низком слое, оставляй его там. Не поднимай код выше без реальной причины.

## Ограничения по слоям

- `entities` только для устойчивых доменных сущностей, не для секций страниц, layout-блоков, одноразовых форм и mock'ов
- `pages` только для route-level экранов
- `features` только для отдельных пользовательских сценариев, не "на будущее"
- не создавай новый слой или модуль без реальной задачи

## Structure hygiene для template repositories

- Не восстанавливай удалённые продуктовые домены, если пользователь явно этого не просил.
- Не создавай placeholder-папки "для будущих проектов".
- Если слой не нужен, не добавляй его.

## Правила Public API

- Импортируй модули через их публичный экспорт.
- Не импортируй внутренние файлы через границы slice'ов.
- Поддерживай понятный `index.ts` или `index.tsx` на границе публичного модуля.

## Правила стилизации и компонентов

- Используй SCSS Modules.
- Предпочитай один компонент на файл.
- Используй `interface Props`.
- Используй `clsx` для условных классов.
- Держи селекторы простыми.
- Переиспользуй компоненты общего UI-kit до создания новых primitive-компонентов.

## Роутинг и композиция

- Route-level код держи в `pages`.
- Если в проекте есть общий route config, используй его.
- Собирай страницы из нижележащих слоёв.

## Cleanup checklist

1. Проверь активные импорты в `app`, `pages`, `widgets`.
2. Удали устаревшие экспорты и пустые директории.
3. Проверь `index.ts` и ссылки после cleanup.
4. Запусти build и lint.
